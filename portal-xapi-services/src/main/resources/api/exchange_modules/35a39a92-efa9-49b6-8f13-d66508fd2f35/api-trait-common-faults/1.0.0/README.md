<h1 style="color:blue">Definición estándar de un error en una API</h1>

<p style="text-align:justify">
La <b>Empresa de Telecomunicaciones de Bogotá (ETB)</b> definió a un <b>error</b> dentro de una API como la composición de un <b>código</b> netamente asignado por el <b>sistema</b>, <b>proyecto</b> o <b>aplicativo</b>, un <b>mensaje</b> orientado a mencionar qué <b>tipología funcional</b> refiere el <b>error</b> y un <b>detalle más técnico</b> útil para el equipo de desarrollo, pruebas, soporte y operaciones.</b>
