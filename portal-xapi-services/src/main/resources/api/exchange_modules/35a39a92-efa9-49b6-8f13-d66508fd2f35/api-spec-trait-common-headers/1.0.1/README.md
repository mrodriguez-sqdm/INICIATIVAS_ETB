# **Atributos o propiedades comúnes en las peticiones de las APIs**

[![Mulesoft](https://img.shields.io/badge/API_Fragment-blue.svg?logo=mulesoft&logoColor=white&label=Mulesoft&style=flat-square)](https://anypoint.mulesoft.com/)

La **Empresa de Telecomunicaciones de Bogotá (ETB)** definió las **propiedades** o **atributos** comúnes entre todos los **llamados**, **invocaciones** o **consumos** de las **APIs**. Dentro de las propiedades se encuentran : **identificador de la petición**, **identificador de la transacción**, **nombre**, **canal**, **versión** y **sistema operativo** del **sistema** o **aplicativo**.
